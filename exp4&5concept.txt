# Experiment 04 — Morphological Analysis & Word Generation

## What we need to add

The purpose of Experiment 04 is to analyze the **structure and forms of words** occurring in YouTube comments.

For example, consider:

```text
"The viewers are watching amazing videos"
```

After morphological processing:

```text
viewers   → view + er + s
watching  → watch + ing
videos    → video + s
amazing   → amaze + ing
```

The exact decomposition depends on the morphological tool/algorithm used.

### How this helps your project

It can help identify related word forms.

For example:

```text
watch
watching
watched
watches
```

These are different surface forms but are related to the same underlying concept.

Similarly:

```text
tutorial
tutorials
```

can be grouped around the concept **tutorial**.

This is useful for your:

* Keyword extraction
* Trend detection
* N-Gram analysis
* Topic detection

# Experiment 05 — N-Gram Language Model

Now we'll add the second missing concept.

## What is an N-Gram?

An N-Gram represents a sequence of **N consecutive words**.

### Unigram

One word:

```text
python
tutorial
audio
quality
```

### Bigram

Two consecutive words:

```text
python tutorial
audio quality
video editing
```

### Trigram

Three consecutive words:

```text
best python tutorial
poor audio quality
advanced video editing
```

---

# Why N-Grams are useful in your project

Your project wants to identify **trending topics and important phrases**.

Individual keywords aren't always enough.

Suppose comments contain:

```text
"audio quality is bad"

"please improve audio quality"

"audio quality needs improvement"
```

Individual keyword analysis might give:

```text
audio
quality
improve
```

But the **bigram model** can detect:

```text
audio quality
```

That's much more informative.

Therefore:

```text
Keyword:
audio

N-Gram:
audio quality
```

The N-Gram gives context.
